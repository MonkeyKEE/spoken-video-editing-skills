# 换电脑复刻｜文策阿峰

**新素材复刻同系列风格**需要本技能、配套风格及制作环境；**同一条片复渲染**还要私下迁移原始可编辑工程及所有依赖。公开遮脸 MP4 和 FCPXML 是合成样片，不能恢复原多轨结构。跨系统即使对齐版本也不保证逐像素一致。

1. 下载完整技能目录，连同 `references/upstream`、MIT 许可和锁定信息；安装兼容的 ChatCut Desktop 并接通宿主的 ChatCut 插件或 MCP。参考 Windows 桌面程序文件版本为 `0.9.15.0`，不是最低版本或跨平台兼容保证。外部宿主可运行 `npx --yes --prefer-online @chatcut/cli@latest connect --no-install --json` 连接现有桌面端；缺桌面端时通过官方渠道安装，由使用者批准。实际枚举 Script、字幕、时间线、MG 与导出工具并绑定当前工程。
2. 从 [风格文件](upstream/styles/black-neon-talking-head/style.yaml) 和批准工程读取字体、字重、色值与布局；迁移时核对实用字体文件和许可。保持 Remotion 或原生 MG 入口、锁文件及全部相对依赖。独立 OpenMotion/HyperFrames 仅在参考确实用到时安装并记录版本，不是本技能的必需运行时。原生 MCP 不强制外置 Node/FFmpeg；CLI/本地验证按选用路线准备，本机观察到 Node.js `v24.19.0`、FFmpeg `9.0.2`，并非最低版本。
3. 私下准备原片、批准参考、合法可用的 B-roll 与当次认可的配乐；保留校对字幕、原始转写和词时码，只有需要重转写才使用获准的本地或云端能力。默认不带青年磁场 MC Logo；身份卡或品牌片尾只按明确许可启用。用 [清单示例](environment.example.json) 记录各素材的实际位置和 SHA-256，将实际清单保存在仓库外。用 Python 3.9+ 运行 `python scripts/preflight.py /path/to/private-manifest.json`；脚本只读核对文件，不安装工具或证明插件已连接。
4. 同片迁移：用原编辑器支持的复制/备份方式迁移完整工程、外链素材、动效、字体和字幕，保留相对路径并用编辑器重新链接。不上传原人像、可关闭遮挡的图层、商业曲、库存源文件或本机路径。记录 OS、桌面/插件版本、字体、FPS、编码器和输出设置，排查离线素材与字体回退。
5. 先用 10–20 秒验收首句、全屏切上下布局、独立无标点字幕带、下方真圆、上方 MG/B-roll 和人声优先的混音。抽查末帧、无重复人声及音画连贯；同片复渲染另比对关键剪点、字幕时码、MG、音轨入点及帧数，并完整解码、实际视听。缺件时写明影响，不把近似当原样。
