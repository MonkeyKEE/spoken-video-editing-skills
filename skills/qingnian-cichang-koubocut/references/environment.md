# 换电脑复刻｜青年磁场 MC

先区分两种目标：**新素材复刻同系列风格**，使用本技能、品牌依赖与参考定稿；**同一条片复渲染**，还要私下迁移原始多轨工程及每项依赖。公开遮脸样片或 FCPXML 只供参考，不能还原原图层。即使版本一致，跨系统字体、编码器与渲染差异也可能导致输出不是逐像素或逐字节相同。

## 搭建与预检

1. 安装兼容的 ChatCut Desktop，登录所需账户，在你的智能体宿主接通 ChatCut 插件或 MCP。Windows 参考制作环境观测到桌面程序文件版本 `0.9.15.0`；不是最低要求或 macOS 兼容保证。外部宿主可先用 `npx --yes --prefer-online @chatcut/cli@latest connect --no-install --json` 连接现有桌面端；没有桌面端时用官方安装入口，安装须由使用者批准。首次操作先枚举工具及读工程，建立明确的项目绑定。技能不包含编辑器、登录授权或渲染服务。
2. 能调用原生时间线、字幕、剪辑、MG 和导出工具后，做一次小样导出。本片视觉与片尾可用 ChatCut 原生 MG；只有参考工程真正引用独立 OpenMotion/HyperFrames 项目时，才从官方安装对应版本并迁移其工程和依赖，或使用原工程所用的无损替代方案（原样复渲染不得擅自替换素材）。Remotion/HTML MG 保留原入口、相对导入、包管理锁文件及图像/字体；不要在另一台机器只复制 JSX 单文件或临时换库。
3. 安装或通过编辑器载入 Noto Sans SC，核对实际字体文件、字重及许可证；本系列参考字幕为 48 px、字重 750（1920×1080 的参考标尺，其他尺寸等比适配）。本机辅助核验观测到 Node.js `v24.19.0` 和 FFmpeg `9.0.2`；使用原生 MCP 时不强制外部 Node/FFmpeg，走 CLI 或脚本路线时才要求对应运行时。不要从观测版本推定最低版本。转写优先迁移原校对字幕、转写及词时码；只有需要新识别才接入获准服务。
4. 私下准备青年磁场 MC 品牌手册与原版横标、批准样片或参考工程、获准的 Cushy《The Grinch》本地文件、原片和本次 B-roll，并核对用途/许可。可用 [清单示例](environment.example.json) 记录本机路径与 SHA-256，把实际清单保存在仓库外。安装 Python 3.9 或更新版本后运行 `python scripts/preflight.py /path/to/private-manifest.json`。这是文件/摘要检查，不证明字体已被实际采用或插件已跑通。不要将实际清单、个人账户、源素材和商业配乐提交到 GitHub。

## 私下迁移同一条片

使用编辑器支持的工程复制或备份方式，复制完整工程、全部外部链接素材、MG 源及它们的依赖、字幕、字体和混音设置。保留相对目录；换盘或换系统后通过编辑器重新链接，不直接改工程内部 JSON。记录桌面端及插件版本、OS、工程 FPS、字体/权重、原素材哈希、LUT、导出设置与编码器。重新打开确认没有离线片段、字体回退或空白 MG；转场与出声位置不得靠拉伸代修。

## 验收

用代表性 10–20 秒抽样覆盖开场、正常字幕、B-roll 圆窗缩移和片尾；确认首秒开口、左侧逐行观点、右侧人物、荧光绿强调、字幕净尾、原版 Logo 与手册标语。对照已批准定稿检视同构画面与配乐，核查 B-roll 不重复、圆窗不漏帧。若复渲染同片，再对照帧数、每个剪点/字幕时码、音轨峰值与入点；完整解码并视听审片。缺必需依赖时报告「缺件/仅近似」，不得声称一模一样。
