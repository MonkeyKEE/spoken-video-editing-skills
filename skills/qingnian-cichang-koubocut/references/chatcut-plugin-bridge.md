# 本地 ChatCut 插件执行桥接

本文件是工作流接入约定，不是自动执行脚本，也不是新插件。用户指定品牌后先锁定品牌、画幅、Logo政策，再调用已有 ChatCut Desktop 工具完成剪辑。不得只给剪辑建议就声称完成出片。

## 品牌分流
- “做文策阿峰 / 剪阿峰口播”→ wenceafeng-koubocut：竖屏，不带青年磁场MC Logo。
- “做青年磁场 / 青年磁场MC / MC口播”→ qingnian-cichang-koubocut：横屏，带真实MC Logo。
- 根据用户明确肯定的制作目标选择；不要把被否定的品牌、比较对象或“不要MC Logo”误当作要做MC。两套都要求时分别建版本；确实不明确才询问。
- 人物相同不代表品牌相同。既有工程属于另一品牌时另建项目或复制时间线，不污染旧片，不将两套流程同时叠加。
- 单次明确覆盖优先，但不将单次修改写成另一品牌的永久默认。分辨率、fps、语速、音乐依当次明确要求；不要把之前一次1080p60导出当作两品牌默认。

## 实际工具路线
1. 加载当前宿主的 chatcut-talking-head-guide；根据任务再加载转写、MG、蒙版、音乐等相关能力指南，不照搬旧工具参数。
2. 通过当前可用的 ChatCut Desktop MCP/插件发现项目与素材，读取项目和时间线，明确本次 projectId。每次项目调用显式传该ID；不能靠历史会话绑定或硬编码旧ID。
3. 素材导入前说明需要的云端转写上传范围。已有合格转写先复用；未获授权不上传到其他网站，不擅自克隆声音。工具缺失时按 chatcut-doctor 排障，不私装另一套插件/软件。
4. 涉及语义删留的剪辑走原生 Script 读写与原子应用；机械停顿清理使用相应能力。保留原片，修改已有成片时创建版本，声画共用剪辑和速度。
5. 原生字幕和项目时间轴是编辑事实来源。MC纯包装修订保留获准字幕。文策阿峰按上游规范在终速干声上转写校对；必要时先导出独立终速干声作为新转写源，不覆盖原片稿、不重复混入人声，也不只比例拉伸旧字幕。遇到无法满足的步骤，记录限制并交待审预览，不能假称规范已完成。
6. 按所选品牌进行语义MG、人物布局、B-roll、字幕与混音。通过原生工具修改、预览和导出；不直接改项目JSON绕过工具限制。MG制作先加载对应能力指南。仓库不含渲染器，不能假称一键执行了不存在的脚本。
7. 查看真实合成与音轨、直接视听审片，核对语义、同步、手机安全区、实际画幅和Logo。指标或静帧不能代替听看；未做的项目明示，文策阿峰按上游规则标待审预览。
8. 通过原生时间线导出并跟踪同一任务直到明确完成。保存、排队和导出完成是不同状态，不重复提交状态不明的任务。核实实际文件后交付；当前IM环境用文件回传工具登记，Web/桌面用宿主文件呈现。未经授权不公开发布。

## 安全及资产
- 缺素材/许可/MC Logo等真正必需输入时只问缺失项；不要每次重复确认已经明确的品牌规则。
- 付费生成须先当前报价并获得确认；部署技能不代表授权购买积分、会员或生成素材。
- 工程及素材优先放G盘，原片、批准版和音乐保持原件，修订有独立版本。
- 不把账户密钥、具体项目UUID、媒体绝对路径或私人聊天写进可共享技能包。
